# Warum du jetzt ein Ziel bist

## Worum es geht

Der Text beschreibt ein sicherheitsökonomisches Modell gezielter
Identitätsangriffe. Er behauptet nicht, dass jeder Nutzer bereits ein lohnendes
Ziel ist, dass ein einzelner kompromittierter Kanal weitere Konten öffnet oder
dass starke Authentifizierung durch KI wertlos wird.

Untersucht wird eine andere Frage: Was geschieht mit dem Risiko, wenn
Vorbereitung, Personalisierung und Koordination eines Angriffs billiger werden?

Von dieser Frage aus untersucht der Text, über welche Systeme digitale Identität
verteilt ist, wie Vertrauen zwischen ihnen weitergegeben wird und wo dadurch
neue Risikokonzentrationen entstehen.

Der Text unterscheidet zwischen belegter Entwicklung, Analogie aus anderen
Deliktfeldern und der eigenen Schlussfolgerung. Wo eine Aussage nicht belegt
ist, steht sie im Konjunktiv. Alle Diagramme sind schematisch und enthalten
keine empirischen Zahlenwerte.
